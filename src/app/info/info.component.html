Source Code
The conversion happens on your machine, in-browser, using JavaScript. No data is sent to any server. This fork maps pfSense 2.7.0 (config revision 22.9) to OPNsense 26.7 (firewall rules, aliases, and gateways in the current MVC format; DHCP pools to dnsmasq).

After upload, a pipeline of input, conversion, and output validators must all pass (warnings are allowed after you acknowledge them) before a config.xml can be downloaded.

Original author: mwood77 (pf2opn, CC BY-NC 4.0).
